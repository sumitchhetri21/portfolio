# JD Portfolio (Static Production Build)

This branch contains the standalone static production build of the interactive portfolio, ready to run directly on GitHub Pages without requiring any build step.

- 🌐 **Live URL**: [https://sumitchhetri21.github.io/portfolio/](https://sumitchhetri21.github.io/portfolio/)
- 💻 **Source Code**: The full Next.js App Router source code is maintained on the [`source`](https://github.com/sumitchhetri21/portfolio/tree/source) branch.

---

## 📁 Branch Contents

- `index.html` — Prerendered portfolio entrypoint
- `404.html` — Prerendered 404 page
- `_next/` — Bundled static CSS, JS chunks, and WebGL/audio assets
- `.nojekyll` — Instructs GitHub Pages not to ignore the `_next` directory
